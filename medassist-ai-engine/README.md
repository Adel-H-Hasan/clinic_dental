# تشغيل خدمة Smile AI على Windows

الخدمة تستخدم SDXL وMediaPipe وليست أداة تشخيص أو توقع سريري معتمد. بقيت أوزان النماذج الأصلية دون استبدال.

## الحالة الحالية

أُنشئت بيئة Python 3.11 محلية في `.venv`، وثُبتت حزم HTTP والصور والاختبار فقط من `requirements-health.txt`. خدمة HTTP تعمل، لكن التوليد **غير جاهز**: لا يوجد رمز خدمة محمّل، ولا حزم Torch/Diffusers/MediaPipe، ولم تُحمّل أوزان SDXL. وجود GPU بذاكرة 4GB لا يثبت كفاية الذاكرة للتوليد. ملف `app/face_landmarker.task` موجود؛ لم يُختبر تحميله بواسطة MediaPipe لأن الحزمة غير مثبتة.

## تشغيل التشخيص فقط

من هذا المجلد:

```powershell
.\run.ps1 -Diagnostics
```

يفتح الخدمة على `127.0.0.1:8001` فقط، ويعطّل التوليد في عملية التشخيص. افحص `/health`: حالة `degraded` و`model_loaded=false` تعني أن خدمة HTTP تعمل لكن النموذج لم يُحمّل. `/capabilities` يصف الوظائف ولا يثبت جاهزية النماذج.

## الاختبارات المحلية

```powershell
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -v
```

اختبار الصورة الناجحة يستخدم Pipeline وهمياً معلناً؛ لا يُعد إثباتاً لنجاح SDXL الحقيقي. اختبارات المصادقة والتحقق من الملفات والأبعاد وحدود الحجم تعمل على التطبيق الحقيقي داخل TestClient.

## استكمال التوليد الحقيقي

يتطلب موافقة المالك قبل تنزيل الحزم الثقيلة أو أوزان النموذج. لم تُنفذ الخطوات الثقيلة التالية:

- تثبيت Torch/Torchvision المتوافقين مع CUDA وفق الإصدارات الموجودة في `requirements.txt`. إصدارات `+cu121` تُجلب من فهرس PyTorch الرسمي؛ لا تفترض أن PyPI وحده يحتويها. ثبّتها أولاً من الفهرس الرسمي ثم بقية المتطلبات.
- توفير نسخة SDXL محلية كاملة متوافقة مع `MEDASSIST_MODEL_ID`. الكود يستخدم `local_files_only=True`، ولذلك **لن ينزّل النموذج تلقائياً**.
- توفير نفس رمز الخدمة سرياً لعمليتي Laravel وPython. `run.ps1` يحترم رمز العملية الموجود أولاً، ثم يقرأ الملف الحالي فقط إذا لزم. لا تكتب الرموز في Git أو المحادثة. لا يحتاج تشغيل التشخيص تغيير `.env` أو `.env.example`.
- بعد استكمال المتطلبات، شغّل `run.ps1` دون `-Diagnostics` واختبر بصورة اصطناعية أو صورة مصرح بها. نجاح `/health` وحده لا يثبت نجاح التوليد.

الخدمة لا تحفظ الصورة في سجلات، وتعيد أخطاء عامة دون مسارات أو تفاصيل داخلية. يقبل الخادم طلب توليد واحداً في الوقت نفسه، ويعيد 503 عند الانشغال بدلاً من حجب حلقة HTTP. الصور خارج قناع الفم تُحفظ في الناتج؛ جودة النتيجة الطبية غير مضمونة. يتطلب اكتشاف المعالم صورة وجه أمامية واضحة، وقد يفشل على اقتصاص الفم وحده.
