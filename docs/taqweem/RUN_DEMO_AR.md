# التشغيل والعرض المحلي على Windows

## البيئة الحالية

افتح PowerShell داخل C:\Users\Orange\Desktop\clinic_dental. الفرع المطلوب feature/taqweem-full-frontend. تحتاج PHP 8.2 أو أحدث مع pdo_mysql وملحقات Laravel، Composer، Node/npm وMySQL من XAMPP. استُخدم Chrome المثبت في المسار الافتراضي للاختبارات.

```powershell
git branch --show-current
php --version
composer install
npm.cmd ci
npm.cmd run build
```

لا تستبدل ملف .env الموجود، ولا تولّد مفتاحاً جديداً لتطبيق الفريق، ولا تشغّل migrate:fresh أو db:wipe. للاستعمال مع قاعدة الفريق بعد اعتماد التغييرات راجع إعدادات .env محلياً دون مشاركتها، ثم شغّل php artisan serve. لا تستخدم بيانات الفريق لإجراء سيناريوهات العرض التالية.

## تشغيل العرض المعزول

1. شغّل MySQL في XAMPP. أدوات QA الحالية مهيأة لـ127.0.0.1:3306 والمستخدم المحلي root دون كلمة سر. إذا كانت بيئتك مختلفة، عدّل أدوات الاختبار فقط بعد مراجعة إعدادات قاعدة مستقلة؛ لا تغيّر إعدادات الإنتاج.
2. البيئة المستقلة موجودة بالفعل في هذا الجهاز. لا تعِد إنشاءها. على نسخة جديدة فقط، يشغّل الأمر التالي إنشاء قاعدة عشوائية جديدة وجداولها وحسابات الاختبار؛ ويرفض الاستبدال إذا وُجد runtime.json.

```powershell
php tools/qa-setup.php
```

3. لتشغيل خادم العرض (إن لم يكن يعمل بالفعل على 8097):

```powershell
php -S 127.0.0.1:8097 -t public tools/qa-router.php
```

افتح http://127.0.0.1:8097. الخادم يستخدم قاعدة اختبار منفصلة وجلسات منفصلة وبريداً مسجلاً محلياً، ويعطّل AI في هذه البيئة. لا يغيّر .env. أوقفه بـCtrl+C في الطرفية التي شغلته. لا تعرض خادم PHP هذا على الإنترنت.

## الحسابات الآمنة

المدير: admin@taqweem.test. الطبيب: doctor@taqweem.test. كلمة السر عشوائية في output/qa-local/runtime.json تحت password، وهي للاختبار فقط. بريد آخر مريض أنشأه اختبار المتصفح موجود في output/qa-local/patient.json ويستخدم كلمة السر نفسها. افتح الملفات محلياً عند العرض ولا تُرسلها أو تُضمّنها في Git أو الحزمة المشتركة. تستطيع أيضاً تسجيل مريض جديد بنفسك من النموذج.

## سيناريو العرض

1. افتح الرئيسية، جرّب EN/العربية وتمرير الرحلة وبوابة الأشعة، ثم التسجيل.
2. سجّل مريضاً ببريد اختباري وكلمة سر مطابقة للشروط. جرّب الدخول قبل التحقق: سيُرفض وفق منطق المشروع الحالي. رابط التحقق الموقّع الحقيقي موجود في output/qa-local/application.log لأن البريد محلي، لا خارجي. افتحه ثم سجّل الدخول.
3. افتح دليل الأطباء، اختر طبيب QA، ثم خدمة QA وتاريخاً مستقبلياً ووقتاً متاحاً. راجع التفاصيل وأرسل. تحقق من ظهور موعد بحالة قيد الانتظار في قائمة المريض.
4. سجّل الخروج، ادخل بالطبيب وافتح المواعيد وأكّد الموعد. لا تحاول إنهاء موعد مستقبلي، فالخادم يمنع ذلك.
5. سجّل الخروج وادخل بالمريض وتحقق من تغيّر الحالة إلى مؤكّد. جرّب تبديل اللغة، ثم تعديل الموعد أو إلغاءه حسب القواعد.
6. في نافذة خاصة جديدة ادخل بالمدير. افتح المستخدمين والأطباء والتخصصات وأنواع المواعيد، وأنشئ نوعاً باسم واضح مثل «اختبار عرض». جميع البيانات هنا معزولة. لا تختبر على قاعدة الفريق.
7. افتح روابط أدوار أخرى من حساب غير مخوّل، وتحقق من الرفض. افتح Smile AI لترى حالة عدم توافر الخدمة، دون الادعاء بوجود توليد حي.
8. بدّل عرض أدوات المطور إلى 390 ثم 768 ثم 1440 بكسل، وتحقق من القائمة والجداول والنماذج باللغتين.

الملاحظات والتقارير تحتاج موعداً مكتملاً وفق قواعد الخادم. اختبار PHPUnit ينشئ بيانات اصطناعية مناسبة في معاملة معزولة ثم يتراجع عنها، ولا يزوّر إكمال موعد مستقبلي في واجهة العرض.

## إعادة الاختبارات

```powershell
$env:APP_KEY = (Get-Content output/qa-local/runtime.json -Raw | ConvertFrom-Json).key
php artisan test
Remove-Item Env:APP_KEY
php artisan view:cache
node tools/test-landing.cjs
node tools/qa-browser.mjs
$env:QA_LANGUAGE = 'ar'
node tools/qa-browser.mjs
Remove-Item Env:QA_LANGUAGE
node tools/qa-responsive.mjs
node tools/qa-cinematic.mjs
node tools/qa-locale-error.mjs
php tools/qa-services.php
git diff --check
```

اختبارات المتصفح تحتاج الخادم 8097 وتضيف بيانات QA اصطناعية في القاعدة المعزولة. لا تمسح قاعدة الاختبار أثناء تشغيلها. إذا امتلأت مواعيد يوم العرض بعد تكرارات كثيرة فاختر تاريخاً مستقبلياً آخر في fixture.json الخاص بالاختبار، ولا تحذف بيانات الفريق.

## اللقطات والأدلة

مجلد output/qa-evidence يحتوي اللقطات الصحيحة المسماة بحسب الدور والمسار واللغة والعرض، مثل patient--patient-dashboard-ar-390.png وadmin--admin-dashboard-en-1440.png وcinematic-portal-ar.png. الملفات ذات الأسماء القديمة العامة وfailure.png نواتج جولات سابقة؛ تعتمد النتيجة النهائية على JSON النهائي واللقطات ذات اللغة والعرض الصريحين، وليس على وجود صورة قديمة.
